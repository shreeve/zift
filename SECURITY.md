# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to
[steve.shreeve@gmail.com](mailto:steve.shreeve@gmail.com) rather than
filing a public GitHub issue.

Include:

- Affected Zift version (`zift version`).
- Operating system and architecture.
- Steps to reproduce, or a proof-of-concept if available.
- Whether the vulnerability is already public.

You will receive an acknowledgement within a reasonable time. A fix and
coordinated release follow once the issue is understood.

## Supported Versions

Only the latest released version is supported. Fixes are released as new
tags on `main`.

## Out of Scope

For operational hardening guidance, threat model, and deployment posture,
see [`docs/security.md`](docs/security.md). That document is for
operators running Zift, not for vulnerability reports.
